需要直接练习和批改时，先在[答题工作簿](ai-agent-interview-workbook.md)填写 Q01–Q05，保存后在对话中告知已完成的题号。

找实际面试机会时，先看[小公司岗位与练手顺序](agent-practice-targets-2026-09-15.md#practice-order)；每家区分完整 JD、列表线索和待确认门槛，投递前以招聘方回复确认当前 HC。

写简历时先看[上下文管理开发负责人：完整条目与精简版](resume-materials.md#context-owner-resume)，按实际职责选择机制和一组量化结果；项目开场可练习[一分钟负责人介绍](context-management-interview-guide.md#owner-introduction)。

按面经做定向准备时先练[100+ 社招面经 Agent 手册](nowcoder-agent-interview-handbook.md)；准备技术深挖时读[岗位追问 F01—F12](agent-hiring-mainland-2026-09.md#hiring-followups)，选一个本人参与的案例；遇到上下文机制追问，再查[技术问答](context-management-interview-guide.md#6-高频面试问题与建议回答)，数字与提交回到[素材库补充](resume-materials.md#recent-interview-updates)核对。

完整历史提交清单见 [development-history.json](../data/development-history.json)，被替代的简短问答见[归档索引](../archive/README.md)。
招聘样本与历史指标保留原日期和口径；链接可访问不等于确认仍有 HC。问答是根据 JD 与项目证据推导的练习题，第一人称回答须按个人实际贡献调整。
